# Atividade-Git-Maxmiliam
Este projeto foi criado com o objetivo de reunir e organizar as anotações das matérias estudadas pelos integrantes do grupo.

Cada integrante ficou responsável por realizar anotações referentes a um determinado estudo/matéria. Dessa forma, o repositório funciona como um espaço colaborativo para armazenar, compartilhar e consultar os conteúdos estudados durante as aulas.

 Matérias

As matérias presentes no projeto são:

 - Estudo Bariônico
 - Educação Física
 - Matemática
 - Geometria Analitica
 - Química

Cada matéria possui suas respectivas anotações, contribuindo para a organização dos conteúdos e facilitando os estudos do grupo.

## Tecnologias utilizadas

- Git (controle de versão)
- GitHub (hospedagem e colaboração)
- Markdown (formatação do README)
- Arquivos de texto (.txt) para as anotações

## Como usar / como rodar

Este projeto não é um programa executável, então não precisa instalar nada além do Git.

1. Clone o repositório:
   git clone https://github.com/biel20075/Atividade-Git-Maxmiliam.git
2. Entre na pasta do projeto:
   cd Atividade-Git-Maxmiliam
3. Abra os arquivos .txt de cada matéria em qualquer editor de texto.
4. Para contribuir, crie ou edite uma anotação, faça o commit e envie com git push.
